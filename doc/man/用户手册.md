# FPlayer Desktop 用户手册

本文档面向最终用户，介绍 `fplayer-ff-desktop` 的主要功能与使用方式。

## 1. 产品功能概览

`fplayer-ff-desktop` 是桌面端音视频工具，核心能力包括：

- 本地媒体播放（文件预览）
- 摄像头预览与推流（含虚拟摄像头）
- 屏幕采集与推流
- 组合模式（多素材画布合成后推流）
- 网络推流（RTMP/RTSP/SRT 等模板）
- 网络拉流（默认预览 + 预览窗口内录制）
- 服务端模式（对接 `fplayer-ff-service`）
- 系统设置持久化（截图/录制目录、推拉流参数与历史）

## 2. 基本入口

在主窗口菜单中：

- `推拉流 -> 推流`
- `推拉流 -> 拉流`

根据场景选择使用。

## 3. 推流怎么用

### 3.1 直连推流（不经过 service）

适用于一对一、局域网临时联调。

1. 打开 `推流` 窗口
2. 选择来源（文件/摄像头/屏幕/组合）
3. 选择协议模板（可选）
4. 填写输出地址
5. 点击 `开始推流`

### 3.2 服务端推流（推荐广播场景）

适用于一对多/多端观看。

1. 先启动 `fplayer-ff-service`，并确认状态为“服务已就绪”
2. 在 service 的 `run/runtime.json` 中获取 `gateway.url`
3. 打开 desktop 推流窗口，选择“推送服务端”
4. 填写：
   - 服务地址：`gateway.url`
   - 服务 app：如 `live`
   - 服务 stream：如 `stream001`
   - 服务类型：`broadcast` 或 `httpflv`
5. 点击 `开始推流`

补充提示：

- 当推流模式选择“推送服务端”时，推流窗口会在日志区前显示红色提示：
  - 分辨率和帧率请勿设置过高，防止服务端负载过大影响拉流稳定性
  - 建议不要超过 `1920x1080 & 60fps`

> 注意：不要手填固定 `:9000`，请以 `runtime.json` 中实际地址为准。

## 4. 拉流怎么用

### 4.1 直连拉流

1. 打开 `拉流` 窗口
2. 输入拉流地址（或用模板+推流码拼接）
3. 点击 `开始拉流`
4. 若需落盘，在拉流预览窗口点击 `录制`

### 4.2 服务端拉流（按 streamId 解析）

1. 确认 service 已就绪
2. 填写服务地址（`gateway.url`）
3. 填写 `streamId`
4. 选择优先协议（建议 `HTTP-FLV`）
5. 点击 `解析地址` 或 `开始拉流`

## 5. 组合模式（多源合成）

组合模式可在一个画布上混合多个来源（文件/摄像头/屏幕）后统一推流。

常见操作：

- 添加/删除素材
- 调整素材位置和层级
- 调整输出分辨率、帧率、码率
- 直接按当前画布布局推流

适合课程录制、演示直播、多源拼接等场景。

模式切换说明（摄像头相关）：

- 从“摄像头模式”进入“组合模式”时，程序会先释放主摄像头占用，再启动组合内摄像头素材。
- 离开“组合模式”时，会释放组合内摄像头占用；再次进入组合模式会自动恢复相机素材绑定。

## 6. 常见问题

### 6.1 `创建失败: Failed to fetch`

通常是服务端模式下 service 未就绪或地址错误：

- 检查 service UI 是否显示“服务已就绪”
- 检查 service 的 `run/runtime.json` 是否生成
- desktop 服务地址是否填写 `gateway.url`

### 6.2 推流成功但看不到画面

- 检查播放端协议是否匹配
- 检查防火墙和端口连通性
- 检查推流地址路径是否正确

### 6.3 拉流无画面

- 先用 ffplay/VLC 验证源地址
- 检查网络连通
- 查看拉流监视窗口日志

### 6.4 组合模式相机素材无画面

- 先确认已使用最新版本（已优化摄像头模式/组合模式切换时的资源释放）
- 先切到其他模式再切回组合模式，触发组合内相机素材重建
- 如问题仍在，请保留“模式切换 + 选择相机素材”全过程日志

## 7. 推荐使用流程（广播）

1. 启动 service（双击 `FPlayerFFService.exe`）
2. 等待 service “服务已就绪”
3. desktop 推流使用服务端模式，服务类型选 `broadcast`
4. 观看端用 desktop 或播放器从 service 拉流

这样是当前最稳、最易维护的用法。

## 8. 系统设置与本地配置

- 主预览与拉流预览都提供 `设置` 按钮，打开”系统设置”页面。
- 当前设置页可配置：
  - 截图保存目录
  - 录制保存目录
  - 屏幕采集后端（DXGI / FFmpeg）
  - 关闭行为（最小化到托盘 / 直接退出）
  - AI 识别配置（API 地址、Key、模型）
  - AI 聊天外观（气泡颜色、文字颜色、字体、字号）
  - 主题切换（深色 / 浅色）
  - 主题色（自定义强调色，浅色模式默认暖珊瑚色 `#cc785c`，深色模式默认蓝色 `#2997ff`）
- 所有颜色色块均可点击，通过系统取色器自由选择。
- 运行过程中会自动缓存推流/拉流常用参数与最近地址。
- 所有配置统一写入：
  - 可执行程序同目录下的 `system_settings.yaml`

## 9. 截图与录制说明

- 截图：
  - 摄像头/屏幕模式下优先按原始帧分辨率保存。
  - 无原始帧可用时回退按预览窗口抓图。
- 主预览录制：
  - 按源链路录制，分辨率不受预览窗口大小影响。
- 拉流预览录制：
  - 采用拉流落盘模式，通常可录到音频（前提是上游流携带音频轨）。
  - 预览窗口录制按钮右侧显示“拉流总时长”（暂停预览不影响，停止拉流后清零）。
  - 录制与截图开始/结束提示为非阻断气泡提示，便于在操作中及时感知状态变化。
