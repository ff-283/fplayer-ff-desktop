- [x] 组合模式下拖拽素材的时候，为什么素材内容不可见？能不能做成拖拽时素材内容也可见呢
- [ ] 当缩放屏幕，或者窗口最大化、取消最大化的时候，屏幕素材会呈现卡顿的画面，且画面不进行刷新。如果此时屏幕素材和其他素材有重叠，那么点击其他素材或者屏幕素材，都能出发强制刷新屏幕素材，使其恢复；如果此时屏幕素材没有和其他素材重叠，那么必须点击此屏幕素材，才能让屏幕素材恢复正常播放。
- [ ] 组合模式下，增加摄像头素材的时候，如果存在一个摄像头素材，再增加一个调用相同摄像头的素材，那么后者会抢占前者的素材，这是正常的；但是前者素材上还是显示正在播放，而不是检测到摄像头被抢占之后进行自动暂停；同时，删除摄像头素材之后，希望所有摄像头素材都能检查一遍自己的素材是否可用，如果可用了，则应该恢复播放状态。另外，其实我现在希望组合模式下，所有素材，除了文件播放素材之外，都不可以暂停或者播放（直接取消那个按钮），取而代之的是左侧素材列表增加素材可见不可见的按钮，如果选择不可见，则画布上直接将这个素材隐藏掉，同时进行暂停，恢复可见，则在画布上显示素材（位置、尺寸都还原），同时进行播放。也就是说，除了文件素材，和被占用的素材（例如两个素材同时用一个摄像头或者同一个屏幕）（被占用的则自动暂停）之外，素材永远都必须一直运行，不能暂停，除非被隐藏。
