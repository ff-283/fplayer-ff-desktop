# 总结与展望

## 1. 总结

FPlayer 完成了一个三端协同的局域网流媒体系统，覆盖从音视频采集、编码推流、服务端分发到终端播放的完整链路。桌面客户端基于 C++17/Qt6/FFmpeg 实现了摄像头、屏幕和文件三种输入源采集、多源画布合成、P2P 和服务端双模式推拉流，并通过策略模式实现了 FFmpeg/Qt6/DXGI 多后端可替换架构。服务端以 ZLMediaKit 为媒体内核、Go Gateway 为控制面、Electron UI 和命令行控制台为管理面，提供了会话编排、地址解析、动态端口分配和公网代理等能力。移动端基于 Flutter 和 media_kit 实现了 HLS/HTTP-FLV/RTMP 多协议播放。三端协同形成采集→分发→播放的闭环，在局域网内 HTTP-FLV 延迟约 1.5 秒，硬编推流 CPU 占用约 8%，服务端内存占用约 120MB，各项指标均达到设计目标。系统全部使用免费开源技术栈，零云服务依赖，便携版免安装部署。

## 2. 展望

当前系统的改进方向集中在四个方面。第一是安全性，引入 Token 鉴权体系和完善的访问控制，使系统从内网可信环境走向公网安全部署。第二是持久化与高可用，接入 Redis 持久化会话数据和流状态，支持 Gateway 多实例部署和故障转移。第三是实时性增强，利用 ZLMediaKit 已有的 WebRTC 能力，将端到端延迟从秒级降至 500 毫秒以内，支撑远程协作和实时互动等场景。第四是边缘扩展，支持多级级联和边缘节点就近分发，适配更大规模的企业和园区部署。
